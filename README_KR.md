# 비교과 프로그램 공지 알림 봇

대학교 비교과 프로그램 공지 웹사이트를 모니터링하여, 특정 키워드가 포함된 공지가 게시될 경우 Discord로 실시간 알림을 전송하는 Python 기반 알림 시스템입니다.  
이 시스템은 최소한의 자원 사용으로 Raspberry Pi에서 24시간 연속 실행되도록 설계되었습니다.

---

## 개발 동기

우리 학교의 비교과 프로그램은 선착순으로 모집되며, 정확한 오픈 시간이 사전에 공지되지 않는 경우가 많습니다.  
수동으로 공지를 확인하다가 기회를 놓치는 일을 방지하기 위해, 새로운 공지를 자동으로 감지하고 즉시 알림을 제공하는 시스템을 구현하고자 했습니다.

---

## 주요 기능

- 로그인 필요 및 동적 렌더링 웹사이트 자동 모니터링  
- Discord 실시간 알림 전송  
- 키워드 기반 공지 필터링  
- Discord 봇 명령어를 통한 런타임 설정 변경  
- Raspberry Pi 환경에서 안정적인 24/7 동작  

---

## 시스템 구조

1. 주기적으로 비교과 프로그램 목록 요청

4. 일치 항목 발견 시 Discord로 알림 전송  
5. Discord 봇 명령어를 통해 동작 상태 및 설정 제어

## 구현 과정 및 주요 의사결정

### 1. 정적 웹 스크래핑 (초기 시도)

`requests`와 `BeautifulSoup`을 사용해 HTML을 직접 스크래핑하는 방식으로 시작했습니다.  
하지만 해당 사이트는 JavaScript로 데이터를 동적으로 렌더링하고 있어, 응답 HTML에 필요한 정보가 포함되지 않는 문제가 발생했습니다.

**배운 점:**  
JavaScript 기반 웹사이트에는 정적 스크래핑 방식이 적합하지 않습니다.

---

### 2. Selenium 기반 스크래핑

Selenium을 도입해 실제 브라우저를 제어함으로써 동적 콘텐츠 로딩에 성공했고,  
로그인 자동화 및 데이터 추출, Discord Webhook 알림까지 구현할 수 있었습니다.

**문제점:**  
Selenium은 Raspberry Pi 환경에서 너무 무겁고 자원 소모가 커, 24시간 상시 실행에는 적합하지 않았습니다.

**배운 점:**  
기능적으로 동작하는 코드가 반드시 운영 환경에서도 적합한 것은 아닙니다.

---

### 3. API 기반 스크래핑 (최종 해결책)

브라우저 개발자 도구의 네트워크 탭을 분석한 결과,  
웹사이트 내부에서 사용하는 AJAX API 엔드포인트를 발견할 수 있었습니다.  
이를 그대로 모방해 헤더와 페이로드를 구성한 API 요청 방식으로 구조를 전면 수정했습니다.

**결과:**  
- Selenium 완전 제거  
- 성능 대폭 향상  
- Raspberry Pi에서 안정적 실행  

**핵심 인사이트:**  
많은 동적 웹사이트는 문서화되지 않은 내부 API를 통해 데이터를 주고받습니다.

## 비동기 스크래핑

Discord 봇은 비동기 방식으로 동작하기 때문에,  
동기 HTTP 요청은 봇 전체를 멈추게 만드는 문제가 있습니다.  
이를 해결하기 위해 `aiohttp`를 사용해 비동기 API 요청을 수행했습니다.

```python
async with aiohttp.ClientSession() as session:
    async with session.post(api_url, headers=headers, data=payload) as res:
        text = await res.text()
```
이 방식으로 스크래핑 작업이 봇의 응답성을 방해하지 않도록 구성했습니다.
